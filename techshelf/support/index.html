TechShelf is the iPhone notebook for your software stack: projects, architecture, encrypted credentials, and cloud spend — with an optional local MCP server for Claude and other assistants.

Where is my data?

On your iPhone. Optionally in your iCloud account if you enable sync. There is no TechShelf cloud account.

Can an AI assistant read my passwords?

No. MCP tools can list credential names and metadata. They cannot read secret values.

The MCP client cannot connect

The phone and the computer must be on the same Wi-Fi. The server runs only while TechShelf is open in the foreground. Copy the pairing command from Settings → MCP Server.

I forgot Face ID access

Face ID is an extra lock on the Credentials tab. Your secrets are still in the encrypted store. Disable Face ID from Settings if the device passcode is available.
