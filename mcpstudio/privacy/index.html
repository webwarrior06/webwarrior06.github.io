Privacy Policy

Last updated: 28 August 2026 · Publisher: Nutiverse

MCP Studio is an iPhone app for connecting to Model Context Protocol (MCP) servers, testing tools, and chatting with AI providers using your own API keys. This policy describes what the app stores and what leaves the device.

Who we are

MCP Studio is published by Nutiverse. Questions: nutiverse@outlook.com.

No account, no Nutiverse backend

MCP Studio does not create a Nutiverse account. There is no Nutiverse server that receives your MCP configurations, API keys, chat messages, or tool results.

What the app stores on your device

All of the following is created by you and stored locally on the device:

  • MCP server names, URLs, headers, and authentication details you enter
  • Discovered tools, resources, prompts, and inspect/test results
  • API keys for OpenAI, Anthropic, and Google Gemini
  • Chat messages while you use the Chat tab
  • Preferences such as language and whether crash reports are enabled

This data never goes to Nutiverse. It leaves the device only when the app connects directly to a server or AI provider you configured, or when Apple processes a purchase.

Third-party connections you control

When you use the app, it connects from your device to:

  • The MCP servers you add, using the URL and credentials you provide
  • The AI provider you choose (OpenAI, Anthropic, or Google Gemini), using your own API key

Those services receive whatever you send them (for example a tool call, a prompt, or a chat message). Their privacy policies apply to that traffic. We do not use your content to train models.

Analytics and crash reports

We use Firebase Analytics for anonymous usage events such as which screens you open and whether a test or purchase succeeded. Events may include names you already entered (for example a server or tool name). They do not include API keys, chat message bodies, MCP payloads, or payment details.

If you leave Diagnostics & Crash Reports on in Settings, we also use Sentry to receive crash and error reports. You can turn that off at any time. Crash reports are scrubbed for common secret headers such as Authorization.

Firebase and Sentry are third-party processors. They may collect standard device and app metadata needed to deliver those services.

Purchases

MCP Studio Premium is sold as an auto-renewing subscription through Apple. Payment is processed by Apple. We do not receive or store card numbers, Apple Account passwords, or other payment details. Apple’s privacy policy applies to that purchase.

Your choices

You can delete API keys in Settings, turn off crash reports, or use Reset Data to clear servers and tests on the device. Deleting the app removes on-device data. Subscriptions are managed in your Apple Account settings.

Children

MCP Studio is not directed at children under 13.

Changes

If this policy changes, the date at the top will be updated.
